Seven visual directions

Internal design previews for choosing the portfolio’s visual direction. Round 1 keeps the approved palette and AG monogram files. Round 2 explores new palettes and new marks. All seven use Amber’s unretouched portrait, existing approved copy, and the three real projects with their genuine screenshots. None of them replaces the current site.

Open the previews through the local preview server so the fonts load: run node docs/design-previews/serve.mjs from the repository root, then visit http://localhost:4400/. Case-study and contact buttons in the previews point to the existing pages in the local app at localhost:3000; the previews contain no forms and send nothing.

Recommendations

Overall: Professional with flair (6). It has the most personality while staying clearly professional, so it suits employers and small-business clients alike. The seal, the hand-drawn underline, and the colored service blocks make it memorable, and the real portrait and projects stay front and center. Cool & savvy’s oversized hero type could be borrowed if you want more punch.

From round 1: Modern studio (2), with Editorial touches. It puts working software first and stays closest to the current approved palette and monogram.

These are recommendations only. New palettes and marks in round 2 are exploratory; nothing changes in the production site until you choose.
